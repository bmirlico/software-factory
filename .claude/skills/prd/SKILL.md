---
name: prd
description: Use when starting a NEW project or a major initiative from an idea. Produces docs/PRD.md (problem, users, journeys, prioritized features, non-goals, metrics). Stops for human validation. Not for single features — use /spec.
---
Lis docs/CONSTITUTION.md. Pose au maximum 5 questions si l'idée est floue (utilisateurs, problème, contraintes, existant, succès). Puis écris `docs/PRD.md` :
1. Problème et contexte (3-5 lignes). 2. Personas (2-3). 3. Parcours clés (user journeys, un par persona).
4. Features en MoSCoW (Must / Should / Could / Won't), chacune : une phrase + valeur + dépendances.
5. Non-objectifs explicites. 6. Contraintes (techniques, légales, délais). 7. Métriques de succès.
Marque `statut: draft`. Affiche et ARRÊTE-TOI. N'écris ni architecture ni code. Attends "PRD validé".
